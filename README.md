### SpendWise

A personal finance backend built with Java, Spring Boot, and PostgreSQL.

* Developed REST endpoints for creating transactions, listing records, and retrieving transactions by ID.
* Separated request handling, application logic, and database access using controller, service, and repository layers.
* Used validation annotations and centralized exception handling to provide consistent HTTP 400 and 404 responses.
* Represented financial amounts with BigDecimal and transaction dates with LocalDate.

[Explore the case study](https://sarpaygen.github.io/projects/spendwise/) · [View source](https://github.com/SarpAygen/SpendWise)

### Computer Vision Desktop Automation

A Python application that uses OpenCV and Tesseract OCR to coordinate actions across up to four Windows application windows.

* Combined image recognition and OCR to interpret changing interface states.
* Tracked actions, retries, and visual confirmation independently for each window.
* Separated background observation from foreground input to coordinate actions without competing focus changes.
* Built a PySide6 interface with window status, capture previews, and diagnostic logs for troubleshooting.
